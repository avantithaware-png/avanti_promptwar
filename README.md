PromptWar
PromptWar is a modern, interactive web application built to challenge and refine your AI prompt engineering skills through real-time head-to-head battles and creative scenarios.

🚀 Features
Interactive Battles: Test your prompts against custom AI models and compare outputs in real time.

Fast & Responsive UI: Built with modern web technologies for zero lag and seamless user experience.

Full-Stack Performance: Powered by a lightweight TypeScript backend running on Bun.

🛠️ Tech Stack
Frontend: Vite, HTML5, TypeScript

Backend & Runtime: Bun

Styling: Modern CSS Frameworks

📦 Getting Started
Prerequisites
Ensure you have Bun installed on your system.
